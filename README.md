# Система донаведення боєприпасів БПЛА (ДЗ №8)

Наскрізний проєкт курсу: розділення системи розрахунку балістики та вибору боєприпасів на статичну бібліотеку ядра та CLI-застосунок, опис збірки в CMake, підтримка трьох режимів конфігурації та діагностика санітайзерами.

## 🏗️ Архітектура проєкту
- **`core`** (статична бібліотека) — уся логіка розрахунку: балістика, вибір оптимального боєприпасу, модель даних. Не містить функції `main` і не виконує файлового вводу/виводу.
- **`app`** (CLI-застосунок) — тонкий адаптер: розбір аргументів командного рядка (`--input-file`, `--output-file`, `--trajectory`), зчитування сценарію, обробка крайніх випадків (`empty scenario`), виклик ядра та запис результату.

---

## 🛠️ Інструкція зі збірки проєкту (CMake)

### 1. Збірка у режимі Debug (Налагодження)
Призначена для відлагодження програми у дебагері (GDB / MSVC / VS Code Debugger). Містить налагоджувальні символи без оптимізацій.
```bash
# 1. Генерація файлів збірки
cmake -B build-debug -DCMAKE_BUILD_TYPE=Debug

# 2. Компіляція проєкту
cmake --build build-debug
```

### 2. Збірка у режимі Release (Реліз)
Призначена для максимальної швидкості обчислень з оптимізаціями компілятора (-O3). Саме на цій збірці вимірюється тривалість `elapsed_us`.
```bash
# 1. Генерація файлів збірки
cmake -B build-release -DCMAKE_BUILD_TYPE=Release

# 2. Компіляція проєкту
cmake --build build-release
```

### 3. Діагностична збірка з Санітайзерами (ASan + UBSan)
Використовується для автоматичного пошуку витоків пам'яті, виходу за межі масивів та невизначеної поведінки.
```bash
# 1. Конфігурація з увімкненими санітайзерами
cmake -B build-san -DCMAKE_BUILD_TYPE=Debug -DENABLE_SANITIZERS=ON

# 2. Компіляція проєкту
cmake --build build-san
```

## 🚀 Запуск застосунку

```bash
./app --input-file <шлях_до_файлу> --output-file <шлях_до_файлу> [--trajectory hover|forward]
```

### Особливість обробки порожнього сценарію:
Якщо кількість цілей у сценарії дорівнює нулю (`count == 0`), програма:
- Виводить у потік помилок `stderr` рядок `empty scenario`;
- Завершується з кодом помилки `1`;
- **Не створює** вихідного файлу.
